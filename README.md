# Wan hu 67 — Landing page

Landing page estática para presentar el proyecto de física sobre lanzamiento de cohetes.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño adaptable y paleta de identidad.
- `script.js`: archivo JavaScript separado (sin animaciones; la página se mantiene estática).
- `assets/wan-hu-67-logo.png`: logotipo proporcionado.

## Paleta de identidad
- Azul profundo: `#0B0F1A`
- Rojo dragón: `#C8102E`
- Crema lunar: `#F5F1E6`
- Gris lunar: `#9CA3AF`

## Ver localmente
Abre `index.html` en un navegador.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube el contenido de esta carpeta (no es necesario subir el ZIP).
3. En el repositorio, entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`, y guarda.
6. GitHub Pages publicará el sitio y mostrará su URL.

No requiere instalación, compilación ni dependencias.
